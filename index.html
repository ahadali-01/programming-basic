01 — Fundamentals

Basic Computer Concepts

These concepts provide the foundation for understanding how computer programs work.

01

Computer Program

The set of instructions given to a computer to perform a specific task is known as a Computer Program or Software.

Examples
  • Visual Studio Code
  • Windows
  • Microsoft Office
  • Google Chrome
02

Data

Data are the facts and figures that are collected, stored, and processed by computers.

Examples
  • 25
  • Ali
  • Pass
03

Output

Output is the processed result produced by a computer after working on the input data.

Examples
  • A printed result card
  • Text message shown on a screen

Programming Fundamentals

A person who knows how to correctly write computer programs is known as a Programmer.
